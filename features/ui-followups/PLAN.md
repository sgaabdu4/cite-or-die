# Fix the two open dialog measure and look findings

Status: Complete

## Outcome + scope

Make the page and the provider dialog measure clean at 390, 768 and 1280 px, and give every form field an outline that meets 3 to 1 contrast. The `shared-edge` finding sat on the footer button row of both dialogs: the buttons sat at the right edge while the hint text sat at the left. At 390 px the provider dialog also scrolled sideways, because its selects set the width of the form. The provider footer buttons now start at the left edge with the text, the form and the fieldsets and labels shrink to the dialog, and the hint rule is shared. The provider hint holds 15 words. The re-index notice is one alert, and the line after Save says "Saved." and no longer repeats it. One opaque token, `field-line`, gives text fields, text areas, selects, the Sources resize handle and the Choose file drop zone a 3 to 1 outline, and a focused field turns its border green. Repeated `look` reviews of the same screens asked for more small changes, kept in scope because the usability rules are fixed for every design. The provider dialog fields fill their row and use the ink colour, buttons, summaries and selects show a green focus outline, the Model hint fits, headings use the heading font and the ink colour, and "Forget settings" stays off, in grey, until a provider config is stored. The provider dialog closes with the same "Close" text button as the citation drawer and opens with focus on its first field, not on Close. The empty chat text no longer names the removed "Set up" step. The page and the dialog share one label style and one field text style, the toggle that opens the token field reads "Access token", not "Auth", in the ink colour of the other outlined buttons, the provider status says "server default" when a tenant has no saved config, which holds whatever provider the server runs and no longer contradicts the dialog, the dialog footer buttons share the page button text style, and a focused field of the provider dialog, select or text, shows the green border and focus ring of a text field on the page, which the dialog field rule hid before. The page loads its changed style and script files under new cache keys, so a browser that kept the old `app.js` cannot import the removed Workspace script. The Workspace dialog, which repeated the Tenant and Matter fields, the Provider settings button and the Choose file control that sit on the page, goes with its "Setup" button and its "Use workspace" button, so changing the tenant or matter takes no extra click; a blank field returns to its default when it changes. The card heading "dev / m_default", which repeated those fields, goes too, and the card pads its content 16 px like the Sources card. On desktop the panes take their height from the page grid, so the page fits the window with no guessed header height and only the chat scrolls. Copy meaning and the one light theme stay the same, and no dark theme is added.
